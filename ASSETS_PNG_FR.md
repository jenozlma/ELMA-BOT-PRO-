# Catalogue des images PNG — ELMA BOT PRO

Toutes les images ci-dessous sont incluses dans `app/src/main/res/drawable-nodpi/`. Les noms sont les noms exacts des fichiers sans extension.

| Fichier PNG | Rôle / écran | Utilisation |
|---|---|---|
| `elma_logo.png` | Logo ELMA BOT PRO | Écran d'accueil et icône déclarée dans AndroidManifest.xml |
| `splash_bg.png` | Fond décoratif bleu nuit avec halo cyan | Illustration de démarrage de référence ; l'écran de lancement Android natif peut être configuré séparément |
| `brain.png` | Icône cerveau cyan | Bouton « Cerveau ELMA » de l'accueil |
| `bot.png` | Icône robot | Bouton « Mon Bot » |
| `console.png` | Icône terminal | Bouton « Console » |
| `sms.png` | Icône de messages | Bouton « Gestion SMS » |
| `settings.png` | Icône engrenage | Bouton « Paramètres » |
| `diagnostic.png` | Icône de diagnostic / graphique | Bouton « Diagnostic » |
| `info.png` | Icône informations | Bouton « À propos » |
| `shield.png` | Icône de sécurité | Ressource prête pour l'écran sécurité |
| `bell.png` | Icône de notification | Ressource prête pour les notifications |
| `database.png` | Icône de stockage | Ressource prête pour sauvegarde/restauration |

Les images sont générées localement pour ce projet, sans dépendance à une URL distante. L'interface actuelle utilise les PNG indiqués comme utilisés ; les trois icônes « shield », « bell » et « database » sont incluses comme ressources pour les écrans complémentaires.
